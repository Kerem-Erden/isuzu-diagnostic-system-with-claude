# Reuse and Redesign Register

Every element taken from the reference repository is listed here. Nothing is copied
in bulk; each item is re-implemented or imported deliberately.

| Old component / file | Purpose | Verification status (old) | Decision | New location | Required change | Rationale |
|---|---|---|---|---|---|---|
| `Data/knowledge-base/isuzu-knowledge.db` | DTC titles, profiles, causes, procedure steps, related live data | Content generated by importer from OEM manuals; schema checked at startup; no `user_version` | **Reuse (data)** | `data/knowledge/isuzu-knowledge.db` | Treated as read-only seed; desktop validates required tables + records a content hash; a separate audit DB holds all writes | 317 DTCs of curated content; re-importing from PDFs is out of scope |
| `Data/knowledge-base/*.json` | Human-readable sources of the DB | Same as above | **Reference only** | not copied | — | DB is sufficient for runtime; JSON stays in old repo as provenance |
| `tools/KnowledgeBaseImporter` (C#) | Builds the DB from JSON | Unknown test coverage | **Not reused** | — | — | Would reintroduce a .NET dependency; DB is reused as an artifact |
| `firmware/.../can_bus.c` | TWAI wrapper on IDF 6 on-chip driver | Loopback PASS once; vehicle TX unproven | **Redesign, reuse lessons** | `firmware/esp32-gateway/main/drivers/twai_adapter.*` | C++ RAII, listen-only default, structured TX enqueue vs completion results, error counters | Keep: TX storage lifetime, `is_tx_success` check, BUS_OFF disable quirk |
| `firmware/.../obd_protocol.c` ISO-TP receive | Bounded reassembly | Host tests pass (mocked) | **Redesign** | `libs/diagnostic-core/src/isotp.cpp` | Pure C++ state machine, no clock/CAN calls, explicit error codes, NRC 0x78 P2* extension | Old code mixes transport, timing and decode; errors collapse to `ESP_FAIL` |
| PID formulas (RPM `(256A+B)/4`, ECT `A-40`, speed `A`, load `A*100/255`, voltage `(256A+B)/1000`) | Mode 01 decode | Host test for RPM only | **Reuse (algorithm)** | `libs/diagnostic-core/src/obd.cpp` | Add tests for all five PIDs | SAE J1979 formulas, verified against standard |
| DTC 2-byte → `P0401` decoding | Mode 03 | Host tested | **Reuse (algorithm)** | `libs/diagnostic-core/src/dtc.cpp` | — | Standard J1979 layout |
| Mode 03 count-byte handling | ISO 15765-4 response `43 NN …` | Host tested | **Reuse (algorithm)**, review | `obd.cpp` | Also accept ECUs that omit padding; reject odd lengths | Fixed in old `bfe44e7` |
| `tests/firmware/test_protocols.c` vectors | Single/multi-frame DTC, bad sequence, NRC | Host pass | **Reuse (test vectors)** | `tests/unit/core/*` | Re-expressed as C++ tests | Known-good vectors |
| `gateway_protocol.c` / `REQ|id|CMD` | Serial commands | Host tested | **Redesign** | `libs/serial-protocol` | Versioned framed lines with CRC, structured errors, shared codec | No version, no checksum, no stage info (ADR-004) |
| Duplicate-clear suppression by request ID | Side-effect guard | Host tested | **Reuse (idea)** | `serial-protocol` + firmware app | Generalised to all side-effect commands | Good safety pattern |
| Clear transaction ordering (scan → snapshot → confirm → one write → rescan, unknown outcome keeps snapshot) | Mode 04 safety | Desktop core test | **Reuse (design)** | `apps/desktop-qt/src/services/clear_dtc_service.*` (future, disabled) | Add RPM/speed/age checks in desktop too | Correct design, needs decoupled audit |
| `SerialGatewayService.cs` close-off-UI-thread rule | Unplug safety on CP210x | Bug-fix history | **Reuse (lesson)** | `apps/desktop-qt/src/transport/` | QSerialPort lives on worker thread | `70ba8cc`, `e70dc4f` |
| `LineFramer.cs` | Bounded line framing, discard oversize through newline | Desktop test | **Reuse (behaviour)** | `libs/serial-protocol/src/line_framer.cpp` | C++ + shared with firmware | Same rule both sides |
| `DtcWorkflow.cs` | Scan/clear orchestration | Desktop test | **Redesign** | `apps/desktop-qt/src/services/dtc_scan_service.*` | Separate acquisition, enrichment, audit outcomes | Old couples audit to scan (defect D3) |
| `DtcKnowledgeRepository.cs` queries | Joins for causes, steps, related live data | Manual + demo | **Reuse (query logic)** | `libs/dtc-knowledge` | Rewritten with Qt SQL; structured errors; no hard-coded titles | Query structure matches DB schema |
| `LiveDataRuleEvaluator.cs` | Hysteresis/confirmation warnings | Desktop test | **Deferred** | — | — | Not in new MVP (R-26) |
| WPF views + palette (`#A5001E` Isuzu red, `#30343B` sidebar text, `#F8F9FA` background, `#D5D8DE` borders, `#68707C` secondary text) | UI | Manual | **Reuse (look & flow)** | `apps/desktop-qt/src/ui` + `style.qss` | Qt Widgets sidebar navigation | Familiar to user |
| `VehicleProfileCatalog.cs` | Model/engine options | Explicitly "temporary prototype options" | **Redesign** | `apps/desktop-qt/src/domain/vehicle_profile.*` | Profile carries ECU addressing; unsupported combinations flagged | Old profile cosmetic (D7) |
| `Kconfig.projbuild` source choice | Simulation vs vehicle | CI build | **Reuse (pattern)** | `firmware/esp32-gateway/main/Kconfig.projbuild` | Add listen-only default, Mode 04 hard-off, pins | Good build-time separation |
| `sdkconfig` (3476 lines, checked in) | Full config | — | **Not reused** | — | Only `sdkconfig.defaults*` are versioned | Machine-generated |
| CI workflow | Build matrix | Unknown last run | **Redesign** | `.github/workflows/ci.yml` | CMake/CTest/Qt + IDF | New toolchain |
